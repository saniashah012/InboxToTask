# InboxToTask Interactive Prototype

## Prototype link

[Open the interactive Figma Make prototype](https://www.figma.com/make/wkm0RSpAXXgFkoAhqKdUJE/Interactive-Laptop-Prototype?fullscreen=1)

## Overview

InboxToTask is a laptop-view proof-of-concept that organizes email-derived tasks and passive communication into two tabs. It helps users notice commitments, review their source emails, and manage deadlines. It also allowed them to add tasks to their calendars. 

## Key interactions

- Switch between Tasks and Passive communication.
- Filter tasks by category, such as homework, jobs and applications, or finances.
- Review deadlines using color indicators and text labels.
- View the original email associated with a task or passive summary.
- Edit, dismiss, or complete tasks.
- Add a task to a simulated external calendar and view the resulting entry.
- Review an updated deadline and track waiting-for items with follow-up reminders.

## Human–AI interaction

### Decision rights
Users control corrections, task dismissal, completion, and calendar additions. The prototype presents extracted information for users to review and act on.

### Interrogation
Source-email links let users check the original message against the task or summary, including its deadline and requested action.

### Trust cues
Deadline labels, source-email access, and updated-deadline indicators help users understand and verify suggestions. Editing and dismissal controls let users correct mistakes.

## Prototype scope

The prototype uses fictional sample data and simulated interactions. It does not process a live inbox, run an AI extraction model, or connect to a real calendar. It demonstrates the interface and user interaction flows rather than production functionality.

The interactive implementation is hosted in Figma Make at the link above; exported source files are not included in this folder.
