# Study materials

Everything a reader needs to repeat the evaluation goes here. Files are listed as they are
planned, so an entry here does not mean the file exists yet. See the
[CP4 plan](../../CP4_PLAN.md#4-evaluation-design).

**Never add real email, participant names, contact details or signed consent forms to this
public repository.** Use participant codes, and keep identifying records privately.

| Planned file or folder | Contents |
| --- | --- |
| `protocol.md` | Session script, timing rules, counterbalancing, scoring rules |
| `consent.md` | Consent form text, plus the instructor's answer on IRB requirements |
| `task_prompts.md` | The task battery as read to participants |
| `questionnaires.md` | UMUX-Lite, satisfaction and trust Likert items, privacy-understanding check |
| `interview_guide.md` | Post-session interview questions |
| `codebook.md` | Thematic analysis codes and how disagreements were resolved |
| `inboxes/` | Fictional inboxes A and B, with the gold labels for each |
| `benchmark/` | Labeled development and held-out sets, and the list of ablation variants |
| `results/` | De-identified session scores and benchmark output |
