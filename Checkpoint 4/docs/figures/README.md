# Figures

Charts, latency plots and diagrams used in the [final report](../FINAL_REPORT.md) and the
presentation. Every chart should be regenerated by a committed script from the data in
[study_materials/results](../study_materials/), so nothing is drawn by hand from numbers
that can't be traced.

Planned figures:

- Architecture and dataflow as deployed
- Time on task and task success, by workflow
- Precision, recall and F1, by workflow (human-only, AI-only, combined)
- Ablation comparison, including tokens per email
- Latency distribution per email and per scan
- Cost per email and per accepted task
- Error categories from the failure analysis
